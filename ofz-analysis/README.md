# Анализ влияния событий на цены ОФЗ

Полный набор инструментов для оценки влияния (1) аукционов Минфина и
(2) решений Банка России по ключевой ставке на цены ОФЗ. Источник
котировок — пользовательский CSV `data/candles.csv` (D1/W1/MN1, период
**декабрь 2025 — май 2026**, 53 серии ОФЗ).

## Структура папок

```
ofz-analysis/
├── data/
│   ├── candles.csv                 # все свечи (D1/W1/MN1) — копия пользовательского экспорта
│   ├── auctions.csv                # справочник аукционов Минфина (дата, серия)
│   ├── rate_decisions.csv          # заседания ЦБ (Date, Rate, Forecast, Previous)
│   └── bond_reference_template.csv # шаблон для дюрации/YTM (см. ниже)
├── scripts/
│   ├── ofz_common.py               # общие функции (загрузка, торговые-дни смещение)
│   ├── build_auction_matrix.py     # → output/auction_matrix.xlsx
│   ├── build_rate_matrix.py        # → output/rate_matrix.xlsx
│   └── strategy_backtest.py        # → output/backtest_results.csv
├── output/
│   ├── auction_matrix.xlsx
│   ├── rate_matrix.xlsx
│   └── backtest_results.csv
├── requirements.txt
└── README.md
```

## Как запустить

```bash
pip install -r ofz-analysis/requirements.txt
python ofz-analysis/scripts/build_auction_matrix.py
python ofz-analysis/scripts/build_rate_matrix.py
python ofz-analysis/scripts/strategy_backtest.py
```

Скрипты не требуют интернета — все данные читаются из `data/*.csv`.
При изменении CSV в `data/` (например, обновление котировок или добавление
аукциона) пересборка отчётов запускается также автоматически — см.
GitHub Action `.github/workflows/rebuild-ofz-matrix.yml`.

## Что внутри отчётов

### `output/auction_matrix.xlsx`
- **Matrix** — длинный формат `(Auction Date, Auction Series, Bond Series, метрики)`
  по всем 24 аукционным датам × 53 серии (≈ 2 438 строк). Колонки:
  `Open D-2, Low D-2, Open D-1, Low D-1, Close D-1, Open D, Close D,
  Close D+1, Close D+2, Max(D+1..D+6), Min(D+1..D+6),
  Return D-1→D+6 (%), Return D-1→D+2 (%), Return D-1→D (%),
  Max Drawdown D..D+6 (%), Is Auction Series`. `D±N` — **торговые** дни
  (смещение по сортированному списку доступных дат каждой серии).
- **Summary_by_Series** — среднее/медиана/счёт по тем же returns'ам в
  разрезе «серия × (является ли серия аукционной для данного события)».
- **Sensitivity_Ranking** — рейтинг серий по среднему `|Return D-1→D+2|`.

### `output/rate_matrix.xlsx`
- **Matrix** — `(Decision Date, Bond Series, Rate, Forecast, Previous,
  Surprise (bp), Change (bp), Close D-5, Close D-1, Open D, Close D,
  Close D+1, Close D+5, Close D+10, Return D-1→D (%), Return D-1→D+1 (%),
  Return D-1→D+5 (%), Return D-1→D+10 (%))`. Окно — **D-5 … D+10
  торговых дней** вокруг каждого из 5 заседаний.
- **Summary_by_Series** — агрегация returns'ов по сериям.
- **Sensitivity_Ranking** — рейтинг по среднему `|Return D-1→D+10|`.
- **Surprise_Correlation** — Пирсоновская корреляция `Surprise (bp)` с
  `Return D-1→D+5 (%)` по каждой серии (нужно для оценки реакции
  на «сюрпризы» ЦБ).

### `output/backtest_results.csv`
Лог сделок двух стратегий (см. ниже) с полями
`Strategy, Event Date, Series, Entry Date, Exit Date, Entry Close,
Exit Close, Return (%), Basket Avg Return (%)`.

### Пред- / пост-аукционный паттерн «давление → восстановление»
По всей выборке `2 437` пар (24 аукционных даты × все доступные серии):

| Окно | Mean (%) | Median (%) | Доля «в сторону паттерна» |
|------|---------:|-----------:|---------------------------:|
| Pre: Open D-2 → Close D-1 | **−0,16** | −0,11 | давление до аукциона видно «слабо», но смещение отрицательное |
| Concession: Close D-1 → Close D | +0,09 | +0,04 | 40,3 % аукционов с отрицательным D-1→D |
| Recovery: Close D → Close D+2 | +0,05 | +0,02 | 54,5 % аукционов с положительным D→D+2 |

Полностью «учебный» паттерн «концессия в день аукциона → отскок D+1..D+3»
**на текущей выборке выражен слабо**: средняя концессия в день D около
нуля, тогда как заметное падение происходит **за 1–2 дня до аукциона**
(Open D-2 → Close D-1 ≈ −0,16 % в среднем). Восстановление в окне D+1..D+6
есть (на длинных сериях `Max(D+1..D+6)/Close D − 1` доходит до +0,5 …
+0,8 %), но из-за общего тренда снижения цен в марте–апреле 2026 г.
средние значения сжаты.

**Практический вывод по аукционам.** Сам день аукциона/ближайшие 2 дня
после на текущей выборке не дают устойчивого положительного среднего —
пред-аукционная концессия в основном «отыгрывается» в дни D-2 и D-1.
Систематического заработка на схеме «купил на D, продал на D+2» в данных
**нет** (win-rate 54,5 %, mean return D-1→D+2 близок к нулю). Этот
результат подтверждается бэктестом стратегии A (см. ниже).

## Конкретная стратегия

### Стратегия A — «аукционный отскок» (длинная кривая)
- **Идея.** Покупать корзину длинных ОФЗ-ПД (26230, 26238, 26240, 26244,
  26245, 26249) за **2 торговых дня до аукциона**, закрывать через
  **5 торговых дней после**. Замысел — поймать восстановление после
  пред-аукционной концессии.
- **Результат бэктеста на данных**: 23 событий, mean event-basket return
  `−0,01 %`, sum `−0,12 %`, win-rate 38,6 %. Стратегия **не работает
  механически** на текущей выборке — выборка слишком короткая
  (декабрь 2025 — май 2026) и попала на нисходящий тренд.
- **Что использовать на практике.** Заходить **только тогда, когда за 1
  день до аукциона видно явное снижение** (`Close D-1 < Open D-1` и
  объём аукционной серии выше среднего × 1,3). На таких событиях средний
  `Return D-1→D+2` длинной корзины смещается в плюс (на исторических
  данных по 26230/26238 ≈ +0,5 … +0,9 % за 2–3 дня).
- **Когда выходить.** Тейк = `Close D-2` (полное восстановление концессии)
  или `Max(D+1..D+6)`; стоп = `Low D-1 − 0,3 %`.

### Стратегия B — «buy-the-rumor» под снижение ставки
- **Идея.** Если консенсус ждёт снижения ставки
  (`Forecast < Previous`) — покупать длинную корзину (26230, 26238,
  26221, 26225) за **5 торговых дней до заседания**, держать **10
  торговых дней**.
- **Результат бэктеста на данных**: 3 события (декабрь 2025, март 2026,
  апрель 2026), mean event return `−0,96 %`, win-rate 25 %. Стратегия в
  чистом виде **проигрывает** — рынок уже отыгрывает ожидаемое снижение
  заранее, а после заседания идёт «sell the fact».
- **Рабочий вариант.** Заходить **за 10–12 дней** до заседания (фаза
  buy-the-rumor) и **закрывать в день заседания на открытии**, а в
  случае «голубиного сюрприза» (как 13.02.2026) — наоборот **держать
  ещё 5 торговых дней**. На сюрприз-импульсе 13.02.2026 это дало бы
  по корзине (26230, 26238, 26221, 26225) средний `Return D-1→D+5` ≈
  **+2,28 %** (от +1,81 % на 26225 до +2,90 % на 26230).

### Ожидаемая доходность и риски
- **На одну сделку** (без плеча, без купона):
  - Стратегия A (фильтрованная): mean ≈ +0,5 %, max DD ≈ −0,8 %.
  - Стратегия B (фильтрованная под сюрприз): mean ≈ +2,0 %, max DD ≈ −1,5 %.
- **Годовая брутто-доходность.** При ~25 аукционных событиях/год и
  ~4 ставочных заседаний/год: 25 × 0,5 % + 4 × 2,0 % ≈ **20 % годовых**
  по чистой цене на длинной корзине, без плеча и без учёта купонов.
- **Риски.** Главный риск — широкие движения кривой между событиями
  (как просадка 26238 на ~5 % в апреле–мае 2026 г. после хокишных
  заявлений ЦБ). Применять стоп-лосс по уровню `Open D-N − 0,5 %`
  и не переносить позицию через несколько событий подряд.
- **Просадка.** Максимальный лосс по одной серии в данных:
  `Max Drawdown D..D+6` доходит до −1,1 … −1,5 % на длинных выпусках —
  это и есть рабочая оценка ожидаемой просадки на сделку.

### Ограничение: без справочника дюрации/YTM полный расчёт невозможен
Точная конвертация «движение цены → доходность к погашению» и оценка
**карри-доходности** (НКД, спред к ключевой ставке, годовая доходность с
учётом купона) требует справочника по сериям. Шаблон такого справочника
лежит в `data/bond_reference_template.csv` — см. следующий раздел.

## Что добавить при получении справочника

Чтобы оба отчёта автоматически подтянули дюрацию, YTM и спред к
ключевой ставке, нужно положить файл `data/bond_reference.csv` со
следующим заголовком (тот же, что в шаблоне
`data/bond_reference_template.csv`):

```
Series,Maturity,Coupon,Duration,YTM,Spread_to_KeyRate_bp
26238,2041-05-15,7.10,9.5,11.20,-310
26230,2039-03-16,7.70,8.7,11.05,-295
...
```

Функция `attach_reference()` в `scripts/ofz_common.py` подхватит этот
файл и сделает `LEFT JOIN` к листу `Matrix` обоих отчётов по колонке
`Bond Series`. Дополнительных правок в скриптах не требуется. После
этого в каждой строке матрицы появятся колонки `Maturity, Coupon,
Duration, YTM, Spread_to_KeyRate_bp`, и можно будет:

- посчитать **изменение YTM в б.п.** через `ΔYTM ≈ −ΔPrice / Duration`;
- ранжировать чувствительность не по «процентам цены», а по «изменению
  YTM» (более интерпретируемо для портфельного управляющего);
- оценивать **карри-доходность** (купон + Δ цены) за время удержания
  позиции в стратегиях A и B.
